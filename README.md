# Math Dash

A dodge game: the Math Dash character stands on a 3-lane floor while random meme objects (chanclas, rubber ducks, moai heads...) are thrown at it from a glowing portal. Move left and right to dodge, and grab stars for bonus points. Every object you dodge is a point, and they come faster the longer you survive.

## Controls
- **Phone:** swipe left/right, or tap the left/right half of the screen
- **Keyboard:** ← / → (or A / D); Space or Enter to start

## Run it
The game is plain HTML/JS in `www/`, with no build step:

```
python3 -m http.server 8000 -d www
# then open http://localhost:8000
```

## Phone apps
`ios/` and `android/` are Capacitor projects that wrap `www/`. See **[RELEASE.md](RELEASE.md)** for building, submitting and updating, and **[store/LISTING.md](store/LISTING.md)** for the store text, screenshots and questionnaire answers.

## Layout
- `www/` – the game: `index.html`, `style.css`, and `js/` (`data.js` = memes, waves, shop items and missions to tune; `save.js` = saved progress and missions; `audio.js` = sound and music; `game.js` = the game; `ui.js` = menus)
- `ios/`, `android/` – native app projects (generated by Capacitor; `npx cap sync` copies `www/` into them)
- `resources/` – source icon and splash images
- `store/` – store listing text, screenshots, feature graphic
- `docs/` – privacy policy and support pages (for GitHub Pages)
